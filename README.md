# GitHub Training Project

## Project Description
This is a modern frontend portfolio project built using React and Vite.

The project contains:
- Responsive Navbar
- Hero Section
- About Section
- Projects Section
- Contact Section
- Footer

## Technologies Used
- React.js
- Vite
- Tailwind CSS
- JavaScript
- Git & GitHub

## Features
- Responsive Design
- Modern UI
- Clean Code Structure
- Fast Performance
